# Linsec
A cybersecurity software I developed during my vocational training, I publish it for others to be able to use it to learn

It consists on controlling some main components: users, network connections and disks
It's  main characteristic are that is camouflaged like a malware would, so that if someone tries to erase Linsec, then it would shutdown and won't turn on until Linsec is repaired or fully erased, finding the control files.
